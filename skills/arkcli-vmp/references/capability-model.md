# 能力模型（VMP × arkcli）

本页固定"什么由控制台做、什么由 CLI 做、什么两边都不做"，用于回答"arkcli 能不能做 X"时避免越界承诺或重复建设。

## 四个维度

| 维度 | 取值 | 说明 |
|---|---|---|
| 对象 | 指标 / 告警 / 通知 / 工作区 / 追踪 / 日志 | VMP 域当前只覆盖指标、告警、通知、工作区 |
| 操作深度 | L0 渲染 / L1 查询 / L2 证据 / L3 判断 / L5 交付 / L4 写入 | 见下表 |
| 执行面 | 控制台 / CLI / 共享 OpenAPI | CLI 只是 OpenAPI 的一种调用方 |
| 产品 | 标品 VMP | 告警后端不同，不能互串 |

## 深度分工

| 深度 | 内容 | 归属 |
|---|---|---|
| L0 | 图表、仪表盘、告警规则表单、Trace 火焰图、日志检索 | 控制台。CLI 不做渲染 |
| L1 | 查询指标、列规则组、取模板、列通知策略 | 两边都做；CLI 输出结构化 JSON |
| L2 | 时间对齐、分片、覆盖率、峰值、逐 EP 证据、发布前后 diff、错误码聚合、TPM 利用率 | arkcli。控制台不产出可审计证据 |
| L3 | 判定口径与业务策略：阈值、发布放行、容量结论、异常处置 | arkcli 提供确定性原子判定（`compare` / `errors` / `capacity`）；Skill 编排层负责阈值选择、例外解释和最终决策 |
| L4 | 建工作区、绑 telemetry、告警规则 CRUD、打标签 | 共享 OpenAPI。单次配置走控制台表单；批量 / 幂等编排走 CLI（先展示参数，写后回读） |
| L5 | 推飞书、写文档/看板、定时巡检 | Skill 编排层 + 宿主能力，不在 CLI 内建 |

## 产品分支

| 产品 | 指标后端 | 告警后端 | arkcli 现状 |
|---|---|---|---|
| 标品（CN） | VMP | VMP 告警（规则组 / 模板 / 通知策略） | 支持采集、查询、告警只读；告警写入走 `arkcli api vmp.*` 原始 action |

**判定规则**：先确认产品。只有标品 CN 的告警是 VMP 告警。

## 明确不做

- 不做仪表盘、Trace 检索、日志检索的渲染或替代。
- 不复制控制台的表单校验；单次告警配置优先引导控制台。
- 不验证通知实际投递（VMP OpenAPI 不暴露投递记录）；只能验证规则存在、启用状态和通知策略绑定。
- 不在 CLI 内建常驻调度；定时由宿主（Skill 编排层）负责。
- 不做权限 / IAM 管理；跨服务授权只做检测与引导。
